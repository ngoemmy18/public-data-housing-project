# Seattle Housing Affordability and Homelessness Trends

## Project Overview

This project explores relationships between housing affordability, rent increases, and homelessness trends throughout Seattle and King County between 2012 and 2024. Using interactive data visualizations, the project examines how rising housing costs and housing cost burden may contribute to broader patterns of housing instability across different Seattle neighborhoods.

The project combines narrative storytelling with data visualization to highlight geographic inequalities in housing affordability and demonstrate how some communities experienced significantly greater rent increases than others.

---

## Features

- Interactive D3.js line chart comparing rent prices and homelessness trends over time
- Interactive D3.js horizontal bar chart showing neighborhood-level rent increases
- Interactive housing cost burden map embedded with Flourish
- Tooltip interactions for charts
- Narrative data storytelling layout
- Responsive editorial-style webpage design

## Data Sources

- Seattle Open Data Portal
- U.S. Census Bureau American Community Survey (ACS)
- U.S. Department of Housing and Urban Development (HUD)
- King County homelessness datasets

---

## Key Findings

- Housing costs increased throughout Seattle between 2012 and 2024.
- Some neighborhoods experienced disproportionately large rent increases.
- Housing cost burden varied significantly across Seattle census tracts.
- Homelessness trends increased during the same period as rising housing costs.
- Affordability pressures were not distributed equally across neighborhoods.
